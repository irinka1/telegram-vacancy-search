# Telegram Vacancy Search Bot

Telegram-бот с мини-приложением для соискателей: ищет вакансии на work.ua и robota.ua по названию должности и формату работы, автоматически расширяет запрос украинскими гендерными формами слова (наприклад "вчитель"/"вчителька"), присылает результаты в чат и сам следит за новыми объявленими.

## Возможности

- Мини-приложение с формой: должность, формат работы (удалённая / частичная / любая), имя в Telegram.
- Два источника: `work.ua` (через публичный текстовый рендер) и `robota.ua` (через headless-браузер, т.к. сайт отдаёт вакансии через JS и защищён антибот-системой).
- Автоматическое расширение запроса гендерными синонимами должности, чтобы не пропускать вакансии с другой формой слова.
- Несколько одновременных поисков на пользователя: новый поиск добавляется к уже отслеживаемым, а не заменяет их.
- Автообновление: бот периодически проверяет новые вакансии по всем активным запросам и присылает только новые.
- Меню-кнопки соискателю: новый поиск, список активных запросов, точечное удаление одного из поисков.
- Отдельная кнопка и уведомления для администратора: список всех активных поисков всех пользователей, оповещение о каждом новом подписчике.
- Подписки переживают перезапуск/деплой бота (сохраняются на диск).
- Rate limiting от спама и флуда (на чат и на IP).
- Скрипт быстрого публичного HTTPS через `cloudflared` — можно протестировать Mini App с телефона без своего домена.

## Технологии

Node.js · Express · Telegraf · Axios · Puppeteer-extra (+ stealth)

## Архитектура

```
public/               — Telegram Mini App (форма поиска вакансий)
src/server/           — Express-сервер и webhook-роут
src/bot/              — Telegram-логика, меню, подписки на автообновление
src/services/workua.js    — парсинг вакансий с work.ua (через text-mirror)
src/services/robotaua.js  — парсинг вакансий с robota.ua (через headless-браузер)
src/services/synonyms.js  — украинские гендерные варианты должностей
src/services/search.js    — объединяет источники и синонимы
```

## Запуск

```bash
npm install
cp .env.example .env   # заполнить своими значениями
npm start
```

После запуска откройте бота в Telegram и отправьте `/start`.

| Переменная | Назначение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен бота |
| `MINIAPP_URL` | публичный HTTPS-адрес мини-аппа |
| `PORT` | порт HTTP-сервера |
| `VACANCY_POLL_INTERVAL_MS` | интервал проверки новых вакансий (по умолчанию 180000 = 3 мин) |
| `ADMIN_CHAT_ID` | чат администратора для уведомлений и списка всех поисков |
| `RATE_LIMIT_WINDOW_MS`, `RATE_LIMIT_MAX`, `BAN_DURATION_MS` | защита от спама и флуда |

## Меню и команды

- `/start`, `/find` — открыть мини-приложение
- 🔎 Новий пошук — открыть форму заново и добавить ещё один поиск (старые продолжают отслеживаться)
- 📋 Перелік вакансій, які вже у пошуку — список всех активных запросов
- 🗑 Видалити пошук — показывает список запросов, выбираешь один — удаляется только он
- 👥 Перелік вакансій (усі) — только для `ADMIN_CHAT_ID`: список активных поисков всех пользователей
- `/stop_updates` — остановить автообновление сразу для всех запросов чата

## Важное про источники

- `work.ua` и `robota.ua` защищены Cloudflare от прямых запросов, поэтому используются либо text-mirror прокси (work.ua), либо headless-браузер со stealth-плагином (robota.ua).
- С серверов в дата-центрах (в т.ч. Hetzner) Cloudflare может периодически ограничивать доступ к robota.ua сильнее, чем с обычных IP — в этом случае бот просто продолжает работать на базе work.ua.

## Быстрый публичный HTTPS для разработки

Для Telegram Mini App нужен публичный HTTPS URL. Скрипт поднимает временный Cloudflare Tunnel без ручного редактирования `MINIAPP_URL`:

```powershell
winget install --id Cloudflare.cloudflared
npm run start:tunnel
```

Что делает скрипт:

- поднимает temporary Cloudflare Tunnel до локального `http://127.0.0.1:3000`;
- находит выданный HTTPS URL вида `https://*.trycloudflare.com`;
- запускает бота с правильным `MINIAPP_URL` и `PORT`.

Tunnel-адрес временный и меняется при каждом запуске; пока открыто окно с `npm run start:tunnel`, бот и mini app доступны извне.
